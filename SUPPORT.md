# Getting help

This Dekan source package does not have a preconfigured public support endpoint. After publishing your fork, add your own issue tracker and contact links here.

For troubleshooting, logs are stored in `%LOCALAPPDATA%\Dekan\logs`. Set `DEKAN_LOG=debug`, reproduce the issue, and inspect the newest log.

For upstream provenance and licensing, see `UPSTREAM-NOTICE.md`.
